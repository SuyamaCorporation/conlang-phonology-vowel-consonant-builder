## Conlang Phonology Vowel & Consonant Inventory Builder

Build a phoneme inventory for a constructed language using a full IPA vowel chart (height × backness) and consonant table (manner × place of articulation). Toggle phonemes in/out, configure syllable structure (onset/nucleus/coda), and generate 20 sample words using the selected phonemes and template. Export the full inventory as text.

**Tech:** Vanilla JS, Tailwind CSS CDN, IPA Unicode characters, no external dependencies.

**How to use:** Click phoneme buttons to add/remove them from your inventory. Set syllable structure dropdowns, then click Generate to see 20 random words. Use Export to copy the inventory to the clipboard.
